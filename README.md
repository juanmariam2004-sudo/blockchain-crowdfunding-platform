# Blockchain-Based Crowdfunding Platform

## About the Project
A decentralized crowdfunding platform designed to allow users to create fundraising campaigns, contribute funds, and manage withdrawals using blockchain technology.

## Technologies Used
- Solidity
- Ethereum (Sepolia Testnet)
- React.js
- Vite
- Tailwind CSS
- MetaMask
- Thirdweb
- Ethers.js
- IPFS / Pinata

## Key Features
- Create crowdfunding campaigns.
- Allow users to donate to campaigns.
- Track campaign funding progress.
- Support milestone-based fund withdrawals.
- Use smart contracts for transparent fund management.

## My Role
Worked on developing, integrating, and testing smart contracts for campaign creation, donations, and milestone-based fund withdrawals.
